TexMacgic

LaTeX editing with Codex, Claude Code, and Antigravity.

TexMacgic is a free app. AI provider accounts and subscriptions are separate.

Use an agent inside your LaTeX project to review source, compile, inspect diagnostics, and check the PDF. TexMacgic connects separately installed command-line providers to editor and document tools through MCP.

AI and agentic integration

Work with an agent in your LaTeX project

Power User mode connects your installed Codex, Claude Code, or Antigravity tool to TexMacgic. Chat accepts file and image context, and the agent can use the app’s editor, build, and document tools.

Project context

Files, images, and selected text

Attach files and images to chat and provide selected text or relevant project content for the task.

Build and inspect

Compiler and PDF tools

The agent can use editor, compiler, diagnostics, PDF, SyncTeX, and TikZ tools while working on your document.

Review changes

Proposed edits and approvals

Review proposed changes and grant approvals in the app. Local file history and reversible edits support checking or undoing changes.

AI features are optional. Provider accounts and tools are installed separately; see the setup and privacy details below.

Features

Editing and compilation

01 / Editing

LaTeX and BibTeX

Edit source with syntax highlighting, autocomplete, and snippets. Search the project and navigate between files.

02 / Compilation

Local TeX compilation

Compile with MacTeX, TeX Live, or TinyTeX installed on your Mac. View compiler errors and use SyncTeX to move between source and PDF.

03 / Figures and tables

Equations, tables, and TikZ

Preview equations, tables, figures, and TikZ code. The app also includes a visual table editor, TikZ Visual Creator, and TikZ Gallery.

Requirements

TeX setup

A compatible TeX distribution must be installed separately. Before opening your first project, complete the Enable Local TeX step described on the support page.

Agent setup and privacy

Your provider account

Install and sign into your chosen command-line provider separately. Power User mode also requires a user-started adapter setup. Before the first request, TexMacgic asks permission to send the provider your prompt and relevant project context, attachments, diagnostics, or tool results. Processing follows your provider account, settings, and privacy terms. You can revoke permission in Settings.
